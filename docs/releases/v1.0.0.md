## Notes

The first release covers:

- **The panel:** plan session and weekly limits with reset times; token totals for today, the week (the plan window) and the billing month; stacked charts by model family with a tokens/cost toggle; breakdowns by model and project; and a comparison of API-equivalent cost with the plan price.
- **Around it:** a settings window, launch at login, and the `claudemon-report` terminal command.
